# Hasini Umesika — Portfolio

A responsive static portfolio website built with HTML, CSS and JavaScript.

## Files
- `index.html` — page content and sections
- `style.css` — layout, responsive styling, transitions and theme styles
- `script.js` — dark/light mode, mobile navigation, reveal animations and back-to-top
- `assets/profile.jpg` — updated profile photo

## Run locally
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Upload to GitHub
1. Create a new repository on GitHub.
2. Extract this ZIP file.
3. Upload `index.html`, `style.css`, `script.js`, `README.md`, and the `assets` folder to the repository root.
4. Commit the files.
5. To publish with GitHub Pages: open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
